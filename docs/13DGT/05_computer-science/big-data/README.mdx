## What's assessed

AS91908 is an **online digital examination** with a printed resource booklet. You write short and/or extended answers totalling **800–1500 words** on **ONE** area you choose in the exam room — this unit is that preparation for the **Big Data** option specifically. Per the specification, questions may cover:

- **Characteristics** of big data (volume, variety, velocity, etc.)
- **Generation, processing and analysing** data in different formats
- **Interpretation and representation** (bias and display)
- **Tools and technologies** used in big data
- **Considerations**: privacy, ethics, and data governance

You'll also be expected to apply this understanding to an **unfamiliar context** in the exam, and to spot where big data overlaps with other computer science areas — most often **artificial intelligence**.

<Callout kind="note" title="Don't confuse this with AS91909">

The specification document covering this unit (`91909-spc-2026.pdf`) covers **both** 91908 and 91909 on the same pages. AS91909 ("Present a reflective analysis of developing a digital outcome") is a **different standard** about your own project work — it is not part of this unit and is not covered here.

</Callout>

## How to use these notes

Each topic explains a mechanism or concept, then works through a **past-paper-style question** so you can see how the ideas are actually examined. NZQA hasn't released marking schedules for these papers, so treat the worked examples as guidance on structure and depth — not a guaranteed mark scheme.

A strong 91908 answer usually does three things:

1. **Explains a mechanism accurately** — in your own words, using the correct vocabulary
2. **Connects it to a specific effect on people** — not "society" in the abstract, but a named group
3. **Reaches a justified conclusion or comparison** — especially for Merit/Excellence-level questions ("discuss", "critically analyse")
